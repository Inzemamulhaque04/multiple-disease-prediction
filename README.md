## 📌 Overview

This project is a **Machine Learning-based web application** that predicts the likelihood of multiple diseases using clinical and biomedical data.

It helps in **early detection and awareness** by providing quick predictions with confidence scores.

## ✨ Features

✅ Predicts multiple diseases:

* ❤️ Heart Disease
* 🩸 Diabetes
* 🧠 Parkinson’s Disease

✅ Clean and interactive UI (Streamlit)
✅ Real-time predictions
✅ Confidence score display
✅ Fast and lightweight

## 📊 How It Works

```text
User Input → ML Model → Prediction → Result Display
```

1. User enters medical details
2. Input is processed by trained ML model
3. Model predicts disease probability
4. Result is shown with confidence score
